# 📘 Educational Site (React)

A modern and responsive educational website built using **React** and **vanilla CSS**. Designed to present courses or learning content in a clean, minimal UI with smooth navigation and responsive layout.

🌐 **Live Demo:** [https://astr1cs.github.io/educational-site-react/](https://astr1cs.github.io/educational-site-react/)

---

## 🛠️ Tech Stack

- **Frontend:** React (Vite), JavaScript (ES6), JSX
- **Styling:** Vanilla CSS
- **Deployment:** GitHub Pages

---

## 📁 Features

- 🎓 Course listing with structured layout
- 💻 Clean component-based architecture
- 📱 Fully responsive on mobile and desktop
- ⚡ Fast loading using Vite build tool
- 🌙 Light, minimal design with smooth user experience
